# CodeAlpha Restaurant Sales Analysis Project

## 📌 Project Overview
This project performs an in-depth **Exploratory Data Analysis (EDA)** and **Data Analysis Dashboard** on a comprehensive dataset consisting of **1,000 restaurant transaction records**. The primary objective is to uncover key business insights, menu performance metrics, and sales trends to enhance operational efficiency and profitability.

## 🛠️ Tools Used
- **Microsoft Excel** (Advanced Level)
- **Pivot Tables & Pivot Charts** for data summarization
- **Data Cleaning Techniques** (Handling missing values, duplicate removal, spelling fixes)
- **Conditional Formatting & Lookup Functions**

## 📊 Key Highlights & Insights
- **Sales Concentration:** Identified the top-performing menu items driving maximum revenue.
- **Time-Period Analysis:** Analyzed sales across different time frames (Afternoon vs. Night) to map peak hours.
- **Payment & Order Dynamics:** Segregated sales patterns based on payment methods and order types (Online vs. Dine-in).
- **Interactive Visualizations:** Created dynamic Excel charts (Bar, Line, and Pie charts) for instant business performance monitoring.
